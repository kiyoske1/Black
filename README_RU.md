# Black Market 2.0 (Minecraft 1.20.1, Forge 47.2.0, Java 17)

## Команды
- `/blackmarket` — рынок: цены (меняются каждые 10 мин), склад. `/blackmarket buy <товар> [кол-во]`
- `/sellpart [all]` — продать товар из руки. `/credits`, `/credits pay <игрок> <сумма>`
- `/rep` — репутация, розыск, долг. Ранги: Новичок → Знакомый(50) → Свой(150) → Авторитет(400) → Легенда(800)
- `/loan take <сумма>` / `/loan pay <сумма>` — займ (+25%, срок 10 мин, лимит 500 + реп×5)
- `/collector pay|talk|refuse` — коллекторы пришли за долгом
- `/police comply|bribe|resist` — полиция пришла на досмотр
- `/orders`, `/orders deliver <№>` — случайные заказы криминальных NPC
- `/auction sell <цена> [минут]`, `list`, `bid <№> <сумма>`, `cancel <№>`, `claim`
- `/casino <ставка>`

## Механики
- **Коллекторы**: просрочил займ — к игроку физически идут 1–3 NPC (растёт при повторах, +10% штрафа). 60 сек на выбор: заплатить / договориться (шанс 35% + реп/10, макс. 80%; +5 мин, но +15% долга) / отказаться (реп −5, бой).
- **Полиция**: «розыск» растёт от продаж, покупок, хранения нелегала в инвентаре. При розыске ≥25 приходят патрули: досмотр (конфискация всех товаров + штраф), взятка (75% успех), сопротивление. «Фальшивый паспорт» сам срабатывает при досмотре.
- **Заказы**: каждые ~4–8 мин от «Анонима», до 3 активных, 15 мин на выполнение; просрочка = −2 репутации.
- **Аукцион**: комиссия 5%, ставки блокируют кредиты, работает с офлайн-игроками (предметы выдаются при входе/`/auction claim`).
- **Редкие товары**: ящик контрабанды, фальшивый паспорт (реп 40), краденый артефакт (150), чёрный алмаз (300). Ограниченный склад, плавающие цены.
- **Банды**: случайные нападения 2–4 бандитов; за убийство — кредиты, репутация, шанс редкого лута.
- Старые балансы (v1.0.0) переносятся автоматически при входе.

## Сборка JAR
Вариант 1 (без установки): залей папку в GitHub-репозиторий → вкладка Actions → «Build mod jar» → скачай артефакт `blackmarket-jar`.
Вариант 2: JDK 17 + Gradle 8.1.1, `gradle build` (нужен интернет) → `build/libs/blackmarket-2.0.0.jar`.
Положи jar в `mods` на сервере и клиентах (Forge 1.20.1).
